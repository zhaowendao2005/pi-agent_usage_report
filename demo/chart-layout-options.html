Token 趋势图 · 布局方案对比 Demo

当前 9 条线挤在一张图里（输入/输出/缓存读/缓存写/TPS×2/首字延迟/总耗时/费用）。下面给出 4 种组织方式，选一个你觉得最合适的。

A分组 Tab 切换

单图区域，顶部 Tab 按指标域切换：Token / 性能 / 费用。每组只放相关的 2~4 条线。

✓ 最简洁，一屏只有一张图，无信息过载；实现改动最小（基本复用现有组件）。✗ 不能跨组对比（比如看不到"延迟升高时费用也在涨"）。

B一主两副（纵向联动）

Token 主图占大面积放顶部，下方并排两张小图（性能、费用）。三张图 缩放/悬浮联动（拖动任意一张的 dataZoom，其它同步）。

✓ 主次分明，Token 是核心指标给最大空间；✓ 可跨组对比且联动缩放。✗ 纵向占用空间大，页面需要滚动。

C2×2 网格仪表盘

四象限等权展示：Token、TPS、延迟、费用。同样支持联动。

✓ 每类指标独立清晰，一眼扫全盘；适合大屏/宽屏。✗ 单图面积小，Token 四线在小图里仍偏挤；窄屏下体验差。

D堆叠面积图 + 迷你指标条

Token 改为堆叠面积（4 条线 → 1 个色块，还能直观看到总量），右轴叠 TPS；下方两条 80px 高的迷你图放延迟和费用，全部联动。

✓ 信息密度最高又不乱，堆叠天然消掉 4 条线的杂乱；✓ 纵向紧凑，不用滚太远。✗ 堆叠后单项数值不如折线直观（靠 tooltip 补足）。
