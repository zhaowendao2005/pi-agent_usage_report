# 📊 仪表盘图表渐进流式渲染与异步优化

## 🎯 优化背景

当系统中积累的数据越来越多（达到数万条甚至数十万条）时，切换时间范围（例如从 24h 切换到 30d）会带来两大性能瓶颈：
1. **数据并行重算开销**：18 个复杂的 ECharts 统计图表需要并发运行 JavaScript 来提取指标、聚合分组、并生成 ECharts Option 配置，导致大量的 CPU 同步占用。
2. **DOM 节点集中渲染阻塞**：18 个 ECharts 实例同时执行 `.setOption()` 并进行画布绘制，主线程被彻底锁死，造成明显的界面卡死、无响应或页面白屏。

为了解决这一经典前端性能瓶颈，我们在 **`StatsView.vue`** 中彻底重构并引入了 **“渐进流式渲染”（Progressive Stream-Rendering）** 和 **“高拟真骨架屏体系”（High-Fidelity Skeleton Placeholder System）**！

---

## 🚀 核心优化设计

### 1. 骨架屏秒开与过渡（Skeleton Screen Placeholders）
我们将 18 个统计图表根据其视觉形态和业务类型，划分为 **6 个独立的流式渲染批次（Batches）**。
- **切换瞬间即时反馈**：当用户切换时间范围（即 `loading` 变为 `true`）时，所有图表瞬间卸载，进入高度拟真的骨架屏占位状态。
- **高拟真个性化设计**：我们没有使用单一乏味的灰色方块，而是根据各个图表的真实几何形态手工设计了专用的骨架组件：
  - **用量趋势骨架**：10 根高度参差、带有微调渐变动画的柱状趋势图占位。
  - **雷达/关系骨架**：由大到小嵌套的多环同心圆骨架，生动模拟雷达辐射区与和风弦图。
  - **性能分析骨架**：由散点星空图占位与网格化热力分布块骨架、以及右侧横向排行榜排版骨架组合。
  - **分布饼图骨架**：完美契合饼图的立体空心圆环骨架，并支持嵌套的双层 Cache 趋势高度自适应。
  - **树图与漏斗骨架**：梯形漏斗、格子树图骨架。
  - **时间轴骨架**：24 小时完整波峰波谷波形骨架。

---

### 2. 渐进流式并行重算与绘制（Staggered Stream-Rendering）
当数据查询完毕（`loading` 变为 `false`），不进行任何同步堆叠渲染，而是启动 **分批渐进调度器**：
- **批次顺序派发**：
  - **Batch 1 (110ms)**：用量趋势（Token 用量、TPS、延迟、单次费用）—— **优先渲染首屏关键视口**。
  - **Batch 2 (190ms)**：模型性能雷达 + 关系弦图。
  - **Batch 3 (270ms)**：TPS 散点图 + 延迟热力图 + 模型排行榜。
  - **Batch 4 (350ms)**：双饼图（Token/费用） + 故障模型拆分 + 缓存命中趋势。
  - **Batch 5 (430ms)**：调用量树图 + 性能转化漏斗 + 错误日光图。
  - **Batch 6 (510ms)**：全天候 24h 时间分布。
  
- **宏任务让出时间切片 (Time-Slicing)**：
  每个批次在渲染后，我们通过 `setTimeout(tick, 80)` **强行给浏览器和 Vue 的布局引擎让出 80ms 的黄金时间切片**。
  这使得浏览器有充足的时间在 60fps 帧率下进行重绘和排版（Paint & Layout），在用户眼前呈现“图表一个接一个如流水般自然生长出来”的极致顺滑、流畅体验，主线程再无半点卡顿！

## 📊 数据流向与批次模型

```
用户切换时间范围 (loading = true)
   ↓
[瞬间切换] 18 个图表进入 6 组特制高拟真骨架屏 (animate-pulse)
   ↓
数据加载完毕 (loading = false)
   ↓
[异步分批渲染轮询器]
├── step 1 (30ms):  渲染 Batch 1 [用量趋势4图]     → 浏览器重绘与排版
├── step 2 (110ms): 渲染 Batch 2 [雷达/关系2图]    → 浏览器重绘与排版
├── step 3 (190ms): 渲染 Batch 3 [性能分析3图]     → 浏览器重绘与排版
├── step 4 (270ms): 渲染 Batch 4 [分布比例5图]     → 浏览器重绘与排版
├── step 5 (350ms): 渲染 Batch 5 [归因转化3图]     → 浏览器重绘与排版
└── step 6 (430ms): 渲染 Batch 6 [时间分布1图]     → 最终页面渲染完成
```
