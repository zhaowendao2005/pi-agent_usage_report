# 使用报告仪表板 - 15 个图表完整指南

## 📊 图表总览

本仪表板包含 **15 个高端可视化图表**，全面展示 LLM 使用数据的各个维度。

---

## 🎯 核心图表（3个）

### 1. TokenTrendChart - Token 使用趋势图 ⭐
- **类型**: 折线图（一主两副联动布局）
- **位置**: 统计卡片下方，全宽展示
- **子图**:
  - 主图：Token 相关（输入/输出/缓存读/缓存写）
  - 副图1：性能指标（TPS 含首字/TPS 纯生成/首字延迟/总耗时）
  - 副图2：费用趋势
- **特色**:
  - 三图 dataZoom 联动缩放
  - Tooltip 独立显示（鼠标在哪显示哪）
  - 每个 Tooltip 显示所有 9 个指标
  - 顶部图例点击隐藏/显示系列
  - 显示模型信息（provider/model）

---

## 🔥 模型对比与关系（2个）

### 2. ModelRadarChart - 模型性能雷达图 ⭐⭐
- **类型**: 雷达图（六维归一化）
- **位置**: 趋势图下方，占 3/5 宽度
- **维度**:
  1. 生成速度（TPS）
  2. 首字响应（TTFT，越低越好）
  3. 完成速度（总耗时，越低越好）
  4. 缓存命中率
  5. 性价比（tokens/$）
  6. 调用规模（次数）
- **交互**:
  - 顶部模型标签可点击切换
  - 支持多模型叠加对比
  - 高亮芯片样式（带光晕效果）
  - Tooltip 显示原始值
- **设计**:
  - 渐变分层背景
  - 半透明填充区域
  - 彩色边框与阴影

### 3. ProviderModelChordChart - 提供商·模型关系弦图
- **类型**: Graph（圆形布局）
- **位置**: 雷达图右侧，占 2/5 宽度
- **展示**: 提供商 → 模型的 Token 流量
- **特色**:
  - 边宽度 ∝ Token 数量
  - 悬停高亮关联路径
  - 带箭头的有向边
  - 节点分类着色（提供商/模型）
  - 支持缩放和旋转

---

## 📈 性能分析（3个）

### 4. TpsScatterChart - TPS vs 延迟散点图
- **类型**: 散点图
- **位置**: 性能分析区，左侧
- **轴**: X=TPS, Y=首字延迟
- **气泡大小**: 费用
- **用途**: 发现性能与延迟的关系，识别最优模型

### 5. LatencyHeatmap - 延迟热力图
- **类型**: 热力图
- **位置**: 性能分析区，中间
- **维度**: 时段（24小时）× 模型
- **颜色**: 绿色（低延迟）→ 黄色 → 红色（高延迟）
- **用途**: 发现高峰时段和模型稳定性

### 6. ModelRankBar - 模型排行榜
- **类型**: 堆叠条形图（横向）
- **位置**: 性能分析区，右侧
- **排序**: 按 Token 总量排序
- **堆叠**: 输入 + 输出 + 缓存读取
- **用途**: 快速识别 Top 模型

---

## 💰 Token 与费用分布（4个）

### 7. TokenPieChart - Token 分布饼图
- **类型**: 环形饼图
- **数据**: 输入/输出/缓存读取/缓存写入占比
- **位置**: Token 分布区，第1个

### 8. CostPieChart - 费用分布饼图
- **类型**: 环形饼图
- **数据**: 各模型费用占比
- **标签**: 显示金额（大于 5% 的扇区）
- **位置**: Token 分布区，第2个

### 9. ModelBreakdownChart - 模型用量双环饼图
- **类型**: 嵌套饼图
- **结构**:
  - 内环：提供商/模型分组
  - 外环：Token 类型细分
- **切换**: 顶部 Tab 切换分组模式（提供商/模型/提供商+模型）
- **位置**: Token 分布区，第3个

### 10. CacheRateChart - 缓存命中率仪表盘
- **类型**: 仪表盘
- **位置**: Token 分布区，右上
- **显示**: 缓存命中率百分比

### 11. CostTrendChart - 费用趋势图
- **类型**: 折线图（累计）
- **位置**: Token 分布区，右下
- **显示**: 累计费用随时间增长曲线

---

## 📊 调用量与错误分析（3个）

### 12. CallVolumeTreemap - 调用量矩形树图
- **类型**: Treemap（矩形树图）
- **层级**: 提供商 → 模型
- **面积**: Token 总量
- **位置**: 调用分析区，左侧
- **用途**: 层级化展示调用量分布

### 13. PerformanceFunnel - 性能漏斗图
- **类型**: 漏斗图
- **层级**:
  1. 总调用
  2. 产生输出
  3. 快速响应（<1s）
  4. 命中缓存
  5. 成功完成
- **位置**: 调用分析区，中间
- **用途**: 展示请求转化率，识别性能瓶颈

### 14. ErrorSunburstChart - 错误旭日图
- **类型**: Sunburst（旭日图）
- **层级**: 提供商 → 错误类型
- **分类**:
  - 4xx 客户端错误
  - 5xx 服务器错误
  - 执行错误
  - 请求中断
- **位置**: 调用分析区，右侧
- **用途**: 多层级展示错误分布

---

## ⏰ 时间分析（1个）

### 15. TimeDistributionBar - 时段分布柱状图
- **类型**: 柱状图
- **位置**: 底部，全宽
- **X轴**: 24小时（0h - 23h）
- **Y轴**: 调用次数
- **渐变**: 蓝色到青色渐变填充
- **用途**: 发现使用高峰时段

---

## 🎨 设计特色

### 统一风格
- **配色方案**: 
  - 主色：蓝色 #3b82f6
  - 辅色：紫色 #a855f7、绿色 #22c55e、橙色 #f59e0b、青色 #06b6d4、红色 #ef4444
- **卡片**: 白底、圆角、边框阴影
- **字体**: 标题 14px 半粗体，描述 11px，图表标签 10-12px
- **Tooltip**: 统一的白色半透明背景 + 边框

### 高端效果
- **渐变填充**: 面积图、热力图使用渐变色
- **光晕效果**: 选中芯片、强调项带光晕阴影
- **平滑动画**: 悬停、切换、缩放有流畅过渡
- **交互反馈**: 悬停高亮、点击切换、联动缩放

### 响应式布局
- **移动端**: grid-cols-1，图表纵向堆叠
- **平板**: grid-cols-2 或 3
- **桌面端**: grid-cols-3, 4, 5，充分利用宽度

## 🚀 使用建议

1. **首次查看**: 从统计卡片 → 趋势图 → 雷达图，快速了解整体情况
2. **性能优化**: 关注 TPS 散点图、延迟热力图，找出慢查询
3. **成本控制**: 查看费用饼图、模型排行榜，识别成本大户
4. **错误排查**: 查看漏斗图、错误旭日图，定位问题根源
5. **时段规划**: 查看时段分布，合理安排调用时间
